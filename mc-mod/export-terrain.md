# 导出地形数据

使用 `/box3export` 命令，将当前世界中由神岛方块构成的区域导出为 `.gz` 地形文件。导出后的文件可以：

- 在其他世界或服务器中**重新导入**（使用 `/box3import`）；
- 配合 [Box3Blocks Unity 包](https://docs.box3lab.com/unity-package) 导入到 Unity 中使用。

## 使用红石块标记区域

`/box3export` 会自动以玩家附近的两个**红石块**（`minecraft:redstone_block`）作为导出区域的**对角点**，形成长方体选区。

```
/box3export <fileName>
```

### 导出规则

- 从玩家位置**由近到远**搜索红石块；
- 找到最近的两个红石块后，将其作为导出区域的对角点；
- 一旦找到两个标记点就停止搜索；
- 搜索**最大半径 1024 格**，超出范围的红石块不会被考虑；
- 如果半径内找不到**两个**红石块，导出会失败。

### 导出范围

::: warning 注意
`/box3export` **仅导出神岛模组相关的方块数据**。导出区域内的原版方块、其他模组方块、自定义模型物品等内容**不会被写入** `.gz` 文件，无法通过 Box3 工具链导入到 Unity 或其他世界中。
:::

### 输出位置

导出文件保存至：`config/box3/<fileName>.gz`

命令中的 `<fileName>` 不需要带 `.gz` 后缀，系统会自动补全。

## 标记点摆放建议

- 使用**两个**红石块，分别放在目标区域的**两个对角**位置。
- 确保两个红石块都在玩家 **1024 格半径内**。
- 同一片区域只保留**一对**标记红石块，避免多对标记导致不确定的结果。
