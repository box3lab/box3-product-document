# 地形导出命令

本页介绍如何使用 `/box3export` 命令，从当前世界中导出一块区域，生成可在其他世界重新导入的 `.gz` 地形文件。

当然，你也可以导入到Unity里，前提：

- 使用 [Box3Blocks Unity包](https://docs.box3lab.com/unity-package) ；

当你在 Minecraft 中得到了满意的场景后，可以配合 Unity 安装包里的工具链，使用本页的 `/box3export` 命令导出地形数据。

## 使用红石块标记导出区域

`/box3export` 会自动在自己附近搜索**两个红石块 `minecraft:redstone_block`**，并把它们当作导出区域的两个对角点，形成一个长方体区域进行导出。

- **语法**：
  - `/box3export <fileName>`

- **导出规则**：
  - 自动在自己附近**从近到远扫描红石块**；
  - 找到最近的两个红石块后，就将这两个方块作为**导出区域的对角点**；
  - 一旦找到两个标记点就停止继续搜索；
  - 搜索的**最大半径为 1024 格**，超出这个范围的红石块不会被考虑；
  - 如果在半径内找不到**足够的两个标记点**，导出会失败（不会生成文件）。

> 导出内容范围：
>
> `/box3export` **只会导出神奇代码岛相关的方块数据**。如果导出区域里包含其他模组方块、原版方块，或者在 MC 里看到的自定义模型，这些内容都不会被写入 `.gz` 文件，也就无法通过 Box3 工具链导入到 Unity 或其他世界中。

- **导出位置**：
  - 导出的文件会保存到：`minecraft/config/box3/<fileName>.gz`
  - 命令中的 `<fileName>` **不需要** 带 `.gz` 后缀，系统会自动补全。

## 标记点摆放建议

- 使用**两个红石块**作为区域对角点，放在区域的**两个对角**；
- 确保两个红石块都在玩家的**1024 格半径范围内**，否则命令可能找不到它们；
- 同一片区域只保留**一对标记红石块**，避免多对标记造成结果不确定；
