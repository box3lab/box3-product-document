# 命令与权限

模组提供了四个命令：三个面向所有平台的功能命令，以及一个 NeoForge/Forge 平台专用的权限管理命令。

## 命令速查

| 命令 | 用途 | 可用平台 |
|------|------|---------|
| `/box3import` | 导入地形文件 | 所有平台 |
| `/box3export` | 导出地形文件 | 所有平台 |
| `/box3barrier` | 切换屏障可见性 | 所有平台 |
| `/box3perm` | 查看/设置权限等级 | NeoForge / Forge |

## 权限管理

::: info 平台限制
`/box3perm` 权限管理命令**仅在 NeoForge 和 Forge 版本中提供**，Fabric 版本不包含此功能。
:::

在 NeoForge / Forge 平台上，`/box3import`、`/box3export`、`/box3barrier` 三个功能命令会根据配置文件中设定的权限等级进行校验。**默认权限等级为 0**，即所有玩家均可使用。

### 查看当前权限等级

```
/box3perm
```

查看当前要求的权限等级，取值范围 `0–4`，对应 Minecraft 的 OP 权限等级。

### 修改权限等级

```
/box3perm <level>
```

将权限要求动态设置为指定等级，**立即生效，无需重启服务器**。

### 权限等级说明

| 等级 | 含义 | 适用场景 |
|------|------|---------|
| 0 | 所有玩家可用 | 公开服务器，允许任何人使用导入导出 |
| 1 | OP 等级 1 以上 | 限制为受信任的玩家 |
| 2 | OP 等级 2 以上 | 更严格的权限控制 |
| 3 | OP 等级 3 以上 | 仅高级管理员 |
| 4 | OP 等级 4（最高） | 仅服主可用 |

例如，如果只希望 OP 等级 2 以上的管理员使用导入导出功能：

```
/box3perm 2
```

设置后，普通玩家执行 `/box3import` 等命令将收到权限不足的提示。
