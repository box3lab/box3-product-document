# Box3Blocks（神岛材质包）for Minecraft

Box3Blocks（神岛材质包） 是一款为 **Minecraft Java 版** 提供神奇代码岛建筑方块与模型支持的模组：

- **373 个神岛原汁原味的方块**，在 MC 里还原神岛的视觉风格。
- **一键将神岛建筑迁移到 Minecraft 中**，无需手动搭建。
- **支持导入神岛模型**，方便你在 MC 里使用已有内容。

安装并启用该模组后，你可以像使用普通方块一样，在创造模式中自由搭建神岛风格的建筑，也可以将神岛中的作品快速搬运到 MC 进行展示或二次创作。

## 安装前准备

Box3Blocks（神岛材质包） 基于 Fabric 框架的模组。

如果你是通过启动器（包括第三方启动器）来游玩，一般都会内置 Fabric 与 Fabric API 的快捷安装入口，通常**不需要手动去各网站单独下载**，只要在启动器里选择对应版本并确认版本号满足上表要求即可。

## 下载与安装方式

你可以在自己的 MC 启动器（包含第三方启动器）里直接搜索模组名称 **Box3Blocks** 并安装；也可以从下列平台手动下载 `.jar` 文件后，放入 `mods` 目录中：

- 去 [CurseForge](https://www.curseforge.com/minecraft/mc-mods/box3-blocks) 安装
- 去 [Modrinth](https://modrinth.com/mod/box3-blocks) 安装
- 去 [Github](https://github.com/box3lab/Box3Blocks-MCMod/releases) 安装

## 验证模组是否安装成功

进入游戏主界面后：

1. 创建或进入任意世界。
2. 将游戏模式切换为 **创造模式**。
3. 打开物品栏（通常在第二页）。

如果你能在物品栏中看到类似下图所示的方块分组界面，说明模组已经成功安装并正常加载：

![](https://cdn-community.bcmcdn.com/47/community/ZUMtBLfXDPbsNbk2y8G2tvLJbuzBlpy9oEM0uVaH2y9Y.png?hash=FqXkR-ou9cY6sej0nonfaWXiJOds)

接下来，你就可以开始：

- 使用新增的神岛方块在 MC 里搭建建筑；
- 尝试使用一键转建筑与模型导入功能，将神岛中的作品迁移到 MC 世界中。
