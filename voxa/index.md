# 释放无限创意，共绘世界之美

VOXA 是一个用于创建体素模型的编辑器，拥有模型和动画制作功能。你可以创建单个模型、多模型组合，并为模型设置动画。

## 多部件建模

用体素建模可以制作房屋、载具等对象，也可以把多个部件组合起来，形成更完整的模型。

![](/QQ20241112-214102.png)

## 骨骼动画

动画功能让静态模型拥有动作。为部件添加 Bone（骨骼）并完成绑定后，可以在动画面板中制作动作；模型导入 Arena 后，即可在地图中播放这些动画。
