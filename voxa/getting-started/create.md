# 创建第一个模型

## 新建模型工程

启动 Creator 后，打开模型列表并选择“新建模型”。选择“自由模式”即可进入 VOXA 模型编辑器。

自由模式用于制作模型、部件、骨骼和动画。换肤模式用于制作角色皮肤；两种类型在创建后不能直接互相转换。

::: info
如果需要制作玩家皮肤，请阅读[换肤模式](/editor/skinningMode)。本入门流程使用自由模式。
:::

## 开始编辑

进入 VOXA 后，可以按以下顺序学习：

1. 使用体素搭建模型外形。
2. 为模型添加部件和骨骼。
3. 创建并预览动画。
4. 保存模型工程，并在 Arena 地图中引用模型资源。
