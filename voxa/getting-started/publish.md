# 保存与交付模型

VOXA 用于制作体素模型、部件和动画。完成模型后，先保存可继续编辑的模型工程，再在 Arena 地图工程中引用该模型。

## 保存模型

1. 完成体素、部件、骨骼和动画编辑。
2. 在预览中检查缩放、方向、碰撞和动画播放。
3. 使用保存功能保存工程文件，并保留源文件用于后续修改。


## 在 Arena 中使用

1. 打开 Arena 地图工程。
2. 在资源管理器中导入或引用已完成的模型资源。
3. 将模型放入场景，并配置需要的脚本、动画和资源引用。
4. 在 Arena 预览中验证模型显示、动画和性能。

## 交付给游玩端

游玩端使用 Arena 导出的 `.boxplay` 发布包。模型会作为地图资源的一部分被包含在发布包中：在 Arena 保存地图工程，导出 `.boxplay`，再由服主在玩家管理后台导入并启动地图。
