# 方块库工作流

菜单入口：`Box3/方块库`

## 界面结构

窗口分为三个区块：

- **World Root** — 根节点管理、Chunk 构建、自动预览
- **Editor Tool** — 编辑工具选择、画笔参数、碰撞/光照策略
- **Block Library** — 方块搜索、分类筛选、方块卡片网格

## World Root（根节点区）

### 字段

- `Root`：当前编辑根节点。所有放置的方块都挂在此节点下。

### 按钮

| 按钮 | 作用 |
|------|------|
| `创建根节点` | 在场景中创建新的 `Box3Root` 对象 |
| `生成Chunk` | 打开 Chunk 构建窗口，默认读取当前 Root |
| `清空根节点` | 删除 Root 下所有方块对象（**不可撤销，谨慎操作**） |

### 自动 Chunk 预览

勾选 `Auto Chunk Preview` 后：

- 每次编辑操作会自动触发 Chunk 重建（0.2 秒防抖）
- 让你实时看到方块转为 Chunk 后的材质和光照效果
- 可以调节预览区尺寸（8-64 格）
- 预览节点挂在 `__AutoChunkPreview` 下

> 编辑中等规模场景时建议开启。大规模笔刷操作时关闭以提升响应速度。

## Editor Tool（工具区）

### 四种编辑工具

| 工具 | 快捷键 | 功能 |
|------|--------|------|
| **Place** | `Shift+1` | 在命中面外侧放置方块（支持画笔体积） |
| **Erase** | `Shift+2` | 删除命中的方块或范围内的方块 |
| **Replace** | `Shift+3` | 将命中方块替换为当前选中的方块 |
| **Rotate** | `Shift+4` | 顺时针 90° 旋转命中方块 |

### 画笔参数

| 参数 | 说明 |
|------|------|
| `Horizontal (X/Z)` | 横向范围（格数）。1 表示单格，3 表示 3×3 区域 |
| `Height (Y)` | 纵向范围（层数）。1 表示单层 |

> 两个参数都有滑条和输入框，方便快速调节和精确输入。

### 额外开关

| 选项 | 默认 | 说明 |
|------|------|------|
| `Hollow Build (Shell Only)` | 关 | 仅放置外壳方块，内部留空 |
| `Generate Collider` | 开 | 放置时是否生成碰撞体 |
| `Collider Mode` | `Full` | 启 Generate Collider 后可选：`Full` / `TopOnly` |
| `Spawn point light when placing emissive blocks` | 开 | 发光方块是否生成实时点光源 |

## Block Library（方块库区）

### 搜索与筛选

- **搜索框** — 输入英文方块 ID 关键词实时过滤
- **分类侧栏** — 按方块分类筛选（`All` 显示全部）
- **Recent** 分类 — 记录最近使用的方块

### 方块卡片

每张卡片显示：

- **名称** — 方块的中文/英文显示名
- **副标题** — 分类标签 + 特性标记（动画、发光、透明）
- **旋转徽标** — 右上角显示当前默认放置朝向（R0/R90/R180/R270）

### 卡片交互

- **左键点击** — 选中方块，设为当前编辑工具使用的方块
- **点击旋转徽标** — 切换该方块的默认放置朝向（顺时针 90° 步进）

### 静态预览与动画预览

- 静态方块显示静态缩略图
- 动画方块（如水流、岩浆）在卡片上以 4 FPS 播放动画预览
- 滚动方块库时动画预览自动暂停以节省性能

## Scene 视图交互

### Place 模式

1. 在 Scene 视图中移动鼠标到方块表面
2. 看到预览线框出现在表面外侧
3. 左键点击放置方块
4. 画笔大于 1×1 时同时放置多个方块

### Erase 模式

1. 鼠标悬停到方块上方，高亮显示将被删除的方块
2. 左键点击删除

### Replace 模式

1. 鼠标悬停到方块上方
2. 左键点击替换为当前选中方块

### Rotate 模式

1. 鼠标悬停到方块上方
2. 左键点击顺时针旋转 90°
3. 连续点击持续旋转

### 拾取回退机制

当场景中没有命中碰撞体时（如相机在空白区域），系统会使用无碰撞拾取逻辑继续尝试定位目标位置，尽力保证工具在空白区域也能正常工作。

## 生成 Chunk（从 Builder 入口）

点击 `生成Chunk` 打开独立配置窗口，默认行为：

- `Source Root`：默认当前 Builder Root
- `Target Parent`：默认当前 Builder Root
- `Realtime Light`：默认 `DataOnly`

详见 [Chunk 构建系统](/art/AL-ChunkSystem) 了解全部参数和调优建议。

## 推荐工作流

1. **创建 Root** → 点击 `创建根节点` 或指定已有对象
2. **选方块搭建主体** → Place 模式 + 调整画笔大小
3. **统一材质风格** → Replace 模式批量替换
4. **调整方向块** → Rotate 模式旋转带方向的方块
5. **开启自动预览** → 查看 Chunk 效果
6. **生成 Chunk** → 最终构建 Chunk 网格

## 注意事项

- 大地图按区域拆多个 Root，便于分别管理和 Chunk 构建
- 编辑卡顿时优先缩小画笔范围，关闭 Auto Chunk Preview
- `清空根节点` 不可撤销，操作前请确认
- 碰撞体模式 `TopOnly` 适用于只有顶面需要碰撞的场景（地面/道路）
