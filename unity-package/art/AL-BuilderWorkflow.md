# 方块库的操作

- 菜单入口：`Box3/方块库`
- 窗口结构：
  - `World Root`
  - `Editor Tool`
  - `Block Library`

## Root 管理（World Root）

### Create Root

- **作用**：快速创建一个用于当前关卡编辑的根节点。

### Clear Root

- **作用**：清空当前 Root 下的所有方块，务必谨慎使用。

**使用建议：**

- 每个功能区使用一个独立 Root（例如：道路、建筑、装饰）；
- 大地图不要把全部内容都挂在同一个 Root 下，便于分块管理与优化。

## 工具模式

### Place

- **操作**：
  - 左键在命中面外侧放置方块；
  - 支持体积画笔（`X/Z` 平面 + `Y` 高度）。

- **适用场景：**
  - 结构搭建；
  - 地表铺设；
  - 大面积批量填充。

### Erase

- **操作**：左键删除命中的方块（或当前画笔范围内的方块）。

- **适用场景：**
  - 清理错误搭建区域；
  - 在墙体上开洞、留门窗等。

### Replace

- **操作**：保持位置不变，将命中的方块替换为当前选中方块。

- **适用场景：**
  - 统一某个区域的材质风格；
  - 调整配色时，一键替换大面积方块。

### Rotate

- **操作**：对目标方块做 90° 步进旋转（循环）。

- **适用场景：**
  - 有方向性的纹理方块；
  - 门窗、指示牌、装饰件的朝向调整。

## 画笔设置

- `Horizontal (X/Z)`：横向范围；
- `Height (Y)`：高度范围。

## 碰撞设置（Editor Tool）

### 生成碰撞体

- **开启时可选模式：**
  - `整体（Full）`：完整方块碰撞，精确但开销更大；
  - `顶面（TopOnly）`：仅生成顶面碰撞，性能更优。

- **关闭：**
  - `None`：不生成任何碰撞。

**关卡配置建议：**

- 主游玩区域：以 `TopOnly` 为默认；
- 确实需要侧向阻挡的区域：局部使用 `Full`；
- 纯装饰区域：可以设置为 `None`，减轻性能压力。

## 发光方块点光源

- 选项：`放置发光方块时生成点光源`
