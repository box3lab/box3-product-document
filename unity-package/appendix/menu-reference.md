# 菜单入口速查

Box3Blocks 全部菜单入口及用途一览。

| 菜单路径 | 功能 | 适用对象 |
|----------|------|----------|
| `Box3/方块库` | 打开方块编辑窗口 — 放置、删除、替换、旋转方块 | 美术 |
| `Box3/地形导入` | 打开地形导入窗口 — 从 .gz 文件或 URL 导入地形 | 美术/程序 |
| `Box3/地形导出` | 打开地形导出窗口 — 将场景中方块导出为 .gz 文件 | 美术/程序 |
| `Box3/图集质量` | 设置方块纹理图集的尺寸和压缩格式 | 美术/TA |
| `Box3/运行时/构建 UV 目录` | 为所有方块预计算 UV 坐标，生成运行时 Catalog 资产 | 程序/TA |
| `Box3/资源/清理未引用 Import 网格` | 删除不再使用的 Chunk 导入网格资产 | 全体 |
| `Box3/编辑端示例/噪音生成` | 打开噪声地形生成示例窗口（需导入 EditorApiDemo Sample） | 程序 |

## 快捷键

以下快捷键仅在方块库窗口打开时生效：

| 快捷键 | 操作 |
|--------|------|
| `Shift + 1` | 切换到 Place 工具 |
| `Shift + 2` | 切换到 Erase 工具 |
| `Shift + 3` | 切换到 Replace 工具 |
| `Shift + 4` | 切换到 Rotate 工具 |
