# Box3Blocks（神岛材质包）for Unity

Box3Blocks（神岛材质包）是一个用于 Unity 的神岛方块工具包，覆盖编辑器搭建、地形导入导出、Chunk 构建和运行时脚本控制。

## 适用对象

- 美术/关卡：快速搭建神岛风格场景，导入导出神岛地形。
- 程序：通过统一 API 在编辑期和运行期操作方块。

## 核心能力

- 方块编辑：放置、删除、替换、旋转、批量操作。
- 地形导入导出：支持地形数据对接外部工具链。
- Chunk 构建：将静态方块构建为 Chunk 网格，便于大地图性能管理。
- Runtime API：运行时动态修改方块世界。

## 环境要求

- Unity：`2022.3 LTS`

## 安装

1. 打开 `Window > Package Manager`
2. 点击左上角 `+`
3. 选择 `Add package from git URL...`
4. 输入：

```text
https://github.com/box3lab/Box3Blocks-unityPackage.git
```

## 菜单入口

- `Box3/方块库`
- `Box3/地形导入`
- `Box3/地形导出`
- `Box3/图集质量`
- `Box3/运行时/构建 UV 目录`
