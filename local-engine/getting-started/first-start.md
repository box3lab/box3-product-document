# 首次启动

按步骤完成数据、网络和密钥配置，再启动需要的服务。本地引擎无需安装运行许可证。

## 1. 打开管理界面

- 桌面版：打开 BOX3 Engine Launcher。
- Linux 服务器：访问安装完成时显示的管理地址，并使用管理端登录密钥登录。

页面打不开时，先确认 Docker 正在运行，再查看[常见问题](/operations/troubleshooting)。

## 2. 配置 PostgreSQL

在“数据配置”中选择一种模式：

- **内置 PostgreSQL**：适合首次使用。等待镜像下载完成，保存自动生成的账号密码，并运行连接检查。数据库只绑定本机地址，不要开放到公网。
- **外部 PostgreSQL**：填写主机、端口、数据库名、用户名和密码；按需设置 SSL，再运行连接测试并保存。

不要在多个引擎实例间共用同一数据库，除非已做好数据隔离。

## 3. 配置 Redis

选择关闭、内置 Redis 或外部 Redis。首次使用可选内置 Redis；Redis 用于缓存和临时状态，不存放永久业务数据。

## 4. 设置访问范围和端口

选择本机、局域网或公网：

- **本机**：仅当前电脑访问，适合创作和测试。
- **局域网**：同一内网或 VPN 的设备访问；其他设备使用引擎电脑的局域网 IP。
- **公网**：填写公网地址。确认 HTTPS 证书、反向代理、系统防火墙和云安全组均已配置。

默认业务端口：Play `3121`、VOXA `3123`、玩家管理 `3124`、登录页面 `3125`、Creator `3127`。Linux Web 管理端默认使用 `3130`。端口冲突时修改配置，并使用界面显示的新地址。

## 5. 保存密钥

按页面要求设置长度足够且互不相同的密钥。Linux 安装器会自动生成密钥；桌面版按提示创建或填写。

- **管理端登录密钥**：登录 Linux Web 管理器。
- **服主管理密钥**：以 owner 身份登录玩家管理后台。

两者不能互换。不要把密钥提交到 Git 或放入网页、地图脚本和截图。

## 6. 启动并检查服务

在“服务总览”选择启动创作端、游玩端或全部服务。首次启动会下载所需镜像并创建容器，等待服务显示健康后再打开页面。

依次确认 Creator、VOXA、Play、登录页面和玩家管理后台可以打开。接口返回 `503` 时先检查玩家服务与数据库状态，再查看[常见问题](/operations/troubleshooting)。
