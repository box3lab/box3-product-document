# 首次启动

目标是先完成配置、启动服务并准备账号。桌面版和 Linux Web 管理器的主要操作相同。

## 1. 打开部署管理器

- **桌面版**：打开 BOX3 Engine Launcher，保持 Docker 运行。
- **Linux 服务器**：打开安装器给出的管理地址，输入管理端登录密钥。

部署管理器负责启动服务；玩家管理后台负责账号和地图，两者不是同一个页面。

## 2. 配置数据服务

进入“**数据配置 → 数据服务**”。

PostgreSQL 用于保存玩家账号和游戏数据。首次使用选择内置模式，不需要另外搭建数据库。

1. PostgreSQL 选择**内置**，按提示启动数据库，等待下载和启动完成。
2. 保留生成的账号和密码，检查连接是否正常，然后保存。
3. Redis 首次使用可以**关闭**；有需要时再启用。

已有数据库时可选外部模式，填写数据库管理员提供的连接信息。不要为已有数据卷随意更换密码。

## 3. 设置访问地址

进入“**数据配置 → 访问设置**”。

| 使用方式 | 选择 |
| --- | --- |
| 只在当前电脑创作或试运行 | 本机 |
| 同一 Wi-Fi / 内网的设备连接 | 局域网 |
| 云服务器或让外网玩家连接 | 公网（共用地址）或公网（独立地址） |

**在自己电脑上初次体验，选“本机”即可。** 云服务器需要配置公网入口，具体填写方式见[局域网与公网访问](/guide/network-access)。

保存配置不会自动启动所有业务服务。暂时不用的组件不必提前安装。

## 4. 选择需要的服务并启动

回到“**服务总览**”，选择用途后点击“**确认启动**”：

| 你的目标 | 选择 |
| --- | --- |
| 编辑地图、制作模型和预览 | 创作端 |
| 导入已发布地图，供玩家游玩 | 游玩端 |
| 既创作又开服 | 两项都选 |

等待所需镜像下载并启动。完成后使用服务卡片上的入口打开页面，**以界面显示的地址为准**。

## 5. 注册玩家，需要创作时再授权

1. 打开服务入口中的**登录页面**，注册玩家账号。
2. 只需要游玩时，直接进入 Play；还没有地图就按[游玩地图管理](/guide/play-maps)导入。
3. 需要创作时，在管理器总览查看并复制**服主密钥**。
4. 打开**玩家管理后台**，选择“服主登录”，输入服主密钥。
5. 在“**创作管理 → 创作权限 → 新增**”中选择刚注册的玩家，开启创作端和需要的操作权限。
6. 使用该玩家账号打开 Creator，开始[创建、预览和发布作品](/guide/create-and-play)。

普通注册账号不会自动成为服主、管理员或创作者。提示“没有创作权限”时，应由服主授权，不是重新注册账号。

想更换登录页面的外观或使用自定义页面，见[登录门户与模板](/guide/login-portal)。先用默认页面跑通登录，再进行替换。

## 默认端口供核对

下面只适用于没有改过端口、没有配置公网路径的情况：

| 页面 | 本机默认地址 |
| --- | --- |
| 游玩端 Play | `http://127.0.0.1:3121` |
| 模型编辑器 VOXA | `http://127.0.0.1:3123` |
| 玩家管理后台 | `http://127.0.0.1:3124` |
| 玩家登录页面 | `http://127.0.0.1:3125` |
| 创作端 Creator | `http://127.0.0.1:3127` |

Linux Web 部署管理器默认端口为 `3130`。不要把管理器地址或服主密钥发给玩家；玩家使用 Play 地址和自己的账号。
