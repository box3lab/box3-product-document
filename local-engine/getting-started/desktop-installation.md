# 安装 BOX3 Engine 桌面启动器

按下面步骤安装启动器。**先安装并启动 Docker，再下载启动器。** Windows 还需要启用 CPU 虚拟化并安装 WSL 2。

## 安装步骤

1. **确认电脑配置。** 建议至少 4 核 CPU、8 GB 内存和 30 GB 可用磁盘空间。镜像、地图和数据库会继续占用磁盘空间。
2. **安装并启动 Docker。** Windows、macOS 请安装 [Docker Desktop](https://www.docker.com/products/docker-desktop/)；Linux 请安装并启动 Docker Engine。等待 Docker 显示运行后再继续。
3. **下载对应版本。** 根据操作系统和处理器架构选择安装包，点击链接即可下载。

   | 系统与处理器 | 下载 |
   | --- | --- |
   | Windows x64 | [下载 BOX3 Engine Launcher](https://assets.box3.fun/local-engine/BOX-Local-Engine-0.3.0-windows-amd64.zip) |
   | Windows ARM64 | [下载 BOX3 Engine Launcher](https://assets.box3.fun/local-engine/BOX-Local-Engine-0.3.0-windows-arm64.zip) |
   | macOS Apple 芯片（ARM64） | [下载 BOX3 Engine Launcher](https://assets.box3.fun/local-engine/BOX-Local-Engine-0.3.0-macos-arm64.zip) |
   | Linux x64 | [下载 BOX3 Engine Launcher](https://assets.box3.fun/local-engine/BOX-Local-Engine-0.3.0-linux-amd64.zip) |
   | Linux ARM64 | [下载 BOX3 Engine Launcher](https://assets.box3.fun/local-engine/BOX-Local-Engine-0.3.0-linux-arm64.zip) |

4. **解压并打开。** 将 ZIP 完整解压到本地目录，再启动 BOX3 Engine Launcher。首次启动时保持 Docker 运行，并按界面提示完成配置；所需服务镜像会按需下载。
