# 桌面版安装准备

本页只介绍桌面版的安装准备，适用于 Windows、macOS 和带桌面环境的 Linux。无桌面服务器、云服务器或需要长期公网运行时，请直接阅读[Linux 服务器安装](/getting-started/linux-installation)。


## 检查电脑配置

桌面版适合个人创作、本机测试和小规模局域网联机。推荐配置如下：

| 项目 | 最低建议 | 推荐配置 |
| --- | --- | --- |
| CPU | 4 核 | 8 核及以上 |
| 内存 | 8 GB | 16 GB 及以上 |
| 可用磁盘 | 30 GB | 50 GB 及以上 |

地图数量、脚本复杂度、同时在线人数和并行运行的地图容器都会影响资源占用。容器配置中的 CPU 和内存是上限，不会在启动时一次性占满。

## 准备 Docker

桌面启动器通过 Docker 运行各项服务：

- Windows 和 macOS 使用 Docker Desktop。
- 带桌面环境的 Linux 使用 Docker Engine 和 Docker Compose v2。

安装启动器前，先完成 Docker 安装并等待 Docker Engine 启动。

可以使用下面的命令检查：

```bash
docker info
docker compose version
```

两条命令都应正常输出。Compose 必须为 v2，即命令形式是 `docker compose`，而不是旧版 `docker-compose`。

::: warning
Docker 需要有足够的磁盘空间。镜像、地图运行时、构建缓存和数据库都会保存在 Docker 或本地引擎的数据目录中。
:::

## 预留磁盘空间

除了启动器本身，还需要空间保存：

- Creator、VOXA、Play 和玩家服务镜像
- PostgreSQL 与 Redis 数据
- 地图工程和游玩地图包
- 模型、图片、音频和构建结果
- 地图运行时容器
- 本地备份

首次使用建议至少预留 30 GB。计划保存较多作品或同时运行多个地图时，建议预留 50 GB 以上。

## 了解许可证流程

业务服务启动前需要安装有效许可证。许可证与当前设备绑定，申请时需要提供启动器显示的设备 ID。

许可证需要在安装并打开启动器后申请，现在不需要提前准备设备 ID。首次启动时按下面的步骤操作：

1. 打开“许可证管理”。
2. 复制设备 ID。
3. 向许可证管理方申请 `.boxlic` 文件。
4. 导入许可证文件。
5. 确认页面显示许可证有效，再启动服务。

许可证适用于个人学习、非商业研究和测试。不要修改设备标识相关配置，否则许可证可能需要重新申请。

## 选择数据服务

本地引擎使用 PostgreSQL 保存玩家、管理员、权限、审计记录和地图脚本的永久数据。你可以选择：

- **内置 PostgreSQL**：适合第一次使用，由启动器创建并管理。
- **外部 PostgreSQL**：适合已经有可用数据库的用户。

Redis 用于缓存、限流计数、一次性会话和构建锁，可以选择内置、外部或关闭。关闭 Redis 不会删除 PostgreSQL 中的永久数据。

::: danger
PostgreSQL 是永久业务数据来源。不要通过删除数据库卷解决登录、权限或连接问题。
:::

## 选择访问范围

本地引擎只有一套访问范围设置，所有服务共用：

| 模式 | 适用场景 |
| --- | --- |
| 本机 | 只有当前电脑使用 |
| 局域网 | 同一 Wi-Fi 或内网中的设备使用 |
| 公网 | 当前电脑具备稳定公网访问条件时使用 |

第一次使用建议选择“本机”。确认创作、游玩和玩家登录都正常后，再根据需要切换到局域网。桌面电脑不适合长期作为公网服务器；需要长期运行时应使用 Linux 服务器部署。

## 安装前检查清单

- [ ] 已下载与当前系统和 CPU 架构一致的桌面版安装包。
- [ ] Docker Desktop 或 Docker Engine 正常运行。
- [ ] Docker Compose v2 可用。
- [ ] 磁盘至少有 30 GB 可用空间。
- [ ] 已决定使用内置还是外部 PostgreSQL。
- [ ] 已决定使用本机还是局域网访问。
- [ ] 知道许可证需要在首次启动后申请和导入。

准备完成后，继续阅读[桌面版安装](/getting-started/desktop-installation)。
