# 安装前准备

在安装本地引擎前，先确认设备、磁盘和网络满足要求。准备工作完成后，安装过程通常不需要手工配置 Docker Compose。

## 选择设备

### 个人电脑

个人创作和本机测试可以使用 Windows、macOS 或带桌面的 Linux。推荐配置如下：

| 项目 | 最低建议 | 推荐配置 |
| --- | --- | --- |
| CPU | 4 核 | 8 核及以上 |
| 内存 | 8 GB | 16 GB 及以上 |
| 可用磁盘 | 30 GB | 50 GB 及以上 |
| 网络 | 首次安装可联网 | 可稳定访问镜像源 |

地图数量、脚本复杂度、同时在线人数和并行运行的地图容器都会影响资源占用。容器配置中的 CPU 和内存是上限，不会在启动时一次性占满。

### Linux 服务器

无桌面服务器支持 `amd64` 和 `arm64` 架构。推荐使用仍在安全支持期内的系统：

- Ubuntu 22.04 或 24.04
- Debian 12
- Alibaba Cloud Linux 2 或 3

一键安装器也可以在 Docker 官方安装脚本支持的部分 CentOS、RHEL 和 Rocky Linux 环境中运行。正式部署前仍建议先在测试服务器验证。

查看服务器架构：

```bash
uname -m
```

| 输出 | 对应架构 |
| --- | --- |
| `x86_64` | `linux-amd64` |
| `aarch64` 或 `arm64` | `linux-arm64` |

## 准备 Docker

桌面版启动器通过 Docker 运行各项服务。安装桌面版前，请先安装并启动 Docker Desktop。Linux 一键安装器会检测 Docker；未安装时会自动安装，已经可用时会跳过。

可以使用下面的命令检查：

```bash
docker info
docker compose version
```

两条命令都应正常输出。Compose 必须为 v2，即命令形式是 `docker compose`，而不是旧版 `docker-compose`。

::: warning
Docker 需要有足够的磁盘空间。镜像、地图运行时、构建缓存和数据库都会保存在 Docker 或本地引擎的数据目录中。
:::

## 准备许可证

业务服务启动前需要安装有效许可证。许可证与当前设备绑定，申请时需要提供启动器显示的设备 ID。

首次启动后按下面的步骤操作：

1. 打开“许可证管理”。
2. 复制设备 ID。
3. 向许可证管理方申请 `.boxlic` 文件。
4. 导入许可证文件。
5. 确认页面显示许可证有效，再启动服务。

许可证适用于个人学习、非商业研究和测试。不要修改设备标识相关配置，否则许可证可能需要重新申请。

## 准备数据库

本地引擎使用 PostgreSQL 保存玩家、管理员、权限、审计记录和地图脚本的永久数据。你可以选择：

- **内置 PostgreSQL**：适合第一次使用，由启动器创建并管理。
- **外部 PostgreSQL**：适合已有数据库或需要独立运维的服务器。

Redis 用于缓存、限流计数、一次性会话和构建锁，可以选择内置、外部或关闭。关闭 Redis 不会删除 PostgreSQL 中的永久数据。

::: danger
PostgreSQL 是永久业务数据来源。不要通过删除数据库卷解决登录、权限或连接问题。
:::

## 准备访问方式

本地引擎只有一套访问范围设置，所有服务共用：

| 模式 | 适用场景 |
| --- | --- |
| 本机 | 只有当前电脑使用 |
| 局域网 | 同一 Wi-Fi、内网或 VPN 内的设备使用 |
| 公网 | 通过公网 IP 或域名访问 |

选择公网时，需要准备公网 IP 或域名，并在云服务器安全组和系统防火墙中放行需要使用的端口。正式公网部署建议配置 HTTPS。

## 安装前检查清单

- [ ] 设备架构受支持。
- [ ] Docker Engine 或 Docker Desktop 正常运行。
- [ ] Docker Compose v2 可用。
- [ ] 磁盘至少有 30 GB 可用空间。
- [ ] 已决定使用内置还是外部 PostgreSQL。
- [ ] 已决定使用本机、局域网还是公网访问。
- [ ] 知道许可证需要在首次启动后申请和导入。

准备完成后，继续阅读[桌面版安装](/getting-started/desktop-installation)或[Linux 服务器安装](/getting-started/linux-installation)。
