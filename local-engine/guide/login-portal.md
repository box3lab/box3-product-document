# 登录门户与模板

登录门户是玩家注册、登录和管理个人账号的页面。Play 和 Creator 都通过它完成玩家登录；账号与权限由引擎的玩家服务统一管理。

## 首次使用

先使用引擎自带的登录页面，按[首次启动](/getting-started/first-start)启动相关服务，再从服务卡片打开登录入口。普通使用不需要下载模板或自行开发页面。

## 想换成自己的登录页面

使用 [BOX3 玩家登录门户模板](https://github.com/box3lab/box3-engine-player-auth-template)，可以调整页面外观、品牌和本站的登录流程。模板提供注册、登录、退出、修改昵称和修改密码功能。

模板需要连接本地引擎，不能单独作为账号系统运行。修改和打包方法见仓库 README；不熟悉开发时，可以请维护者基于模板提供已打包的登录镜像。

## 在部署管理器中使用

1. 获取与你的引擎版本配套、且适合服务器 CPU 架构的登录页面镜像。
2. 按镜像提供者的说明，将镜像导入运行引擎的 Docker 环境。
3. 打开“**数据配置 → 访问设置 → 登录页面镜像**”，填写导入后的完整镜像名和版本标签。
4. 保存配置，并重新启动相关服务。
5. 从服务卡片打开登录页面，验证注册、登录、退出，以及返回 Play 或 Creator 的流程。

这里填写的是 **Docker 镜像名**，不是模板仓库链接，也不是登录网页地址。公网域名、端口和路径仍在[访问设置](/guide/network-access)中配置。

## 独立公网地址也能共享登录

登录门户和 Play、Creator 可以使用不同域名或 IP。玩家登录后，会返回原来的应用，并同步当前账号的登录状态。

请保持引擎相关组件与模板版本配套。定制页面时，保留模板的登录跳转流程；不要只修改返回链接，或把密码、密钥写入前端页面。

自定义镜像不会因为引擎更新而自动换成新版本。模板有更新时，请重新打包镜像、使用新的版本标签，再到管理器中替换并验证。
