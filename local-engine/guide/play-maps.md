# 游玩地图管理

“游玩地图”用于管理发布后的 `.boxplay` 地图包。拥有相应权限的管理员可以导入、检查、更新和删除地图，不要求必须使用 owner 身份。

## 导入地图包

1. 启动游玩端。
2. 登录玩家管理后台。
3. 打开“游玩与管理 → 游玩地图”。
4. 选择 `.boxplay` 文件。
5. 等待地图包解析完成。
6. 检查地图和资源列表。
7. 确认内容后完成导入。

如果文件是 `.boxproject`，应返回 Creator 导入，不能继续安装到游玩端。

## 地图包预览

导入前可以查看：

- 主地图和副地图
- 地图 ID
- 服务端与客户端脚本
- 图片和音频
- 其他地图资源

预览过程不会执行地图脚本。资源列表较长时，可以在弹窗内滚动查看，不需要扩大到超过屏幕高度。

## 更新地图

Creator 修改完成后重新发布 `.boxplay`，再在游玩地图中执行更新。

更新前建议：

1. 导出当前游玩包或创建文件备份。
2. 备份 PostgreSQL 中的重要数据。
3. 确认新包仍使用正确的地图 ID。
4. 避免在玩家在线时替换地图。
5. 更新后测试登录、进入、传送、房间和存档。

## 删除地图

删除入口只在地图组的主地图上显示，因为该操作会删除整个地图组。副地图不单独显示相同的删除操作，避免误以为只会移除一张副地图。

删除前确认：

- 没有玩家仍在地图中。
- 不再需要当前地图组。
- 已经保存需要保留的游玩包和数据。
- 已经了解删除影响范围。

## 地图导入失败

提示地图 ID 无效或地图包解析失败时，检查：

- 文件是否由兼容版本 Creator 正常发布。
- 是否手工修改过包内清单。
- 主地图和副地图关系是否完整。
- 上传是否中断。
- 临时目录和数据目录是否有足够空间。

保存请求时间、状态码和错误消息，再查看 Play 与玩家服务日志。不要连续重复提交同一个失败文件。

## 导入后的配置

地图导入完成后，在[容器与资源管理](/guide/maps-and-containers)中设置运行方式、玩家上限、房间上限、空闲回收时间和资源组，然后使用测试玩家进入地图验证。
