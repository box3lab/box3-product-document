# 游玩地图管理

玩家管理后台的“游玩地图”用于管理已发布的 `.boxplay` 文件。拥有对应权限的管理员即可操作，无需 owner 身份。

## 导入地图

1. 启动游玩端并登录玩家管理后台。
2. 打开“游玩管理 → 游玩地图”，选择导入。
3. 选择 `.boxplay` 文件并等待解析。
4. 检查地图 ID、主副地图、脚本和资源预览。
5. 确认内容后完成导入，并设置[地图容器配置](/guide/maps-and-containers)。

`.boxproject` 是 Creator 的可编辑工程，不能导入游玩地图。预览只展示内容，不会执行地图脚本。

## 更新地图

1. 在 Creator 中修改地图并重新发布 `.boxplay`。
2. 备份当前地图包和重要 PostgreSQL 数据。
3. 确认新包使用正确的地图 ID，尽量在没有玩家在线时更新。
4. 在游玩地图中选择更新并上传新包。
5. 测试登录、传送、房间和存档。

## 删除地图组

删除入口只显示在地图组主地图上，删除会影响整个地图组。操作前确认没有玩家在线，已备份需要保留的数据，并了解删除范围。

## 导入失败时

1. 确认文件由兼容版本的 Creator 正常发布，且扩展名是 `.boxplay`。
2. 不要手工修改包内清单；必要时从 Creator 重新发布。
3. 确认磁盘临时空间充足，上传已完成。
4. 记录失败时间、请求状态和错误消息，再查看 Play 与玩家服务日志。

不要连续重复提交同一个失败文件。
