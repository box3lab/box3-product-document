# 作品管理

Creator 的作品用于组织可编辑地图工程。每个作品可包含一个主地图和多个副地图。

## 创建作品

1. 启动创作端并打开 Creator。
2. 选择“新建作品”，填写名称和基本信息。
3. 创建主地图，并按需要添加副地图。
4. 保存后进入 Arena 编辑内容。

地图 ID 是系统内部标识。配置或排查时使用页面显示的 ID，不要用作品名称、版本号或资源 hash 代替。

## 导入作品

1. 选择 `.boxproject` 文件。
2. 确认文件来源可信、版本兼容且磁盘空间足够。
3. 在 Creator 中导入并检查地图、资源和脚本。

`.boxplay` 是发布后的游玩包，不能导入 Creator 作为可编辑工程。

## 导出与迁移

1. 保存作品并结束当前编辑。
2. 导出 `.boxproject`，在目标设备的 Creator 中导入。
3. 检查地图组、资源和脚本，再运行预览测试。

工程文件不包含玩家数据库。迁移完整服务器还需单独备份 PostgreSQL、Play 地图库、VOXA 数据和配置。

## 备份与删除

删除作品前先导出 `.boxproject`。删除 Creator 中的工程不会删除已经导入 Play 的地图包，两边需分别管理。

建议保留当前 `.boxproject`、已发布的 `.boxplay`、版本记录，以及更新前的数据备份。地图发布流程见[创作、预览与发布](/guide/create-and-play)。
