# 创作、预览与发布

按以下流程从地图工程制作可游玩的 `.boxplay` 地图包。

## 先了解文件类型

| 文件 | 用途 |
| --- | --- |
| `.boxproject` | Creator 可编辑的工程 |
| `.boxplay` | Play 可导入的发布包 |

两种文件不能互相替代。

## 1. 创建工程

1. 在启动器中启动创作端并打开 Creator。
2. 新建作品，填写名称和基本信息。
3. 创建主地图，再按需要添加副地图。
4. 进入 Arena 编辑场景和逻辑。

Arena 操作请阅读[Arena 编辑器手册](https://docs.dao3.fun/arena/)。

## 2. 制作模型（可选）

打开 VOXA，新建或导入模型，编辑部件、体素、骨骼或动画，保存后在地图中使用。详情见[VOXA 编辑器手册](https://docs.dao3.fun/voxa/)。

## 3. 预览并测试

使用 Creator 的预览功能启动地图。发布前确认主地图正确、脚本可编译、资源已保存，并在 Play 环境测试多人进入、传送、房间和存档。

## 4. 发布地图包

1. 保存所有地图、脚本和资源。
2. 在 Creator 中选择地图组并发布。
3. 保存生成的 `.boxplay` 文件。

发布包包含游玩所需的地图快照、脚本和资源，不包含完整的可编辑工程。不要在客户端脚本中保存秘密。

## 5. 导入 Play

1. 启动游玩端，并登录玩家管理后台。
2. 打开“游玩管理 → 游玩地图”，选择导入。
3. 选择 `.boxplay` 文件，等待解析完成。
4. 检查地图、脚本和资源预览，确认后完成导入。
5. 在[地图容器配置](/guide/maps-and-containers)中设置运行方式和资源限制。
6. 使用测试玩家进入地图，检查登录、传送、房间和存档。

地图包预览不会执行地图脚本。如果提示地图 ID 无效，请从兼容版本 Creator 重新发布，不要手工修改包内清单。

## 更新地图

1. 备份当前 `.boxplay` 和重要数据库数据。
2. 在 Creator 中修改并重新发布地图包。
3. 确认地图 ID 和地图组关系正确，尽量在没有玩家在线时更新。
4. 更新后重新测试登录、传送、房间和存档。
