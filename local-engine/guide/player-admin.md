# 玩家管理后台

这里管理玩家账号、创作权限、已发布地图和运行状态。它与负责安装、启动服务的部署管理器不同。

## 先分清三种身份

| 身份 | 如何登录 | 用途 |
| --- | --- | --- |
| 玩家 | 登录页面注册的账号和密码 | 游玩；获授权后可以创作 |
| 服主 | 后台“服主登录”，输入服主密钥 | 初始化并完整管理服务器 |
| 管理员 | 后台“管理员登录”，使用独立管理账号 | 按权限组参与日常管理 |

玩家密码不能用于管理员登录。Linux 安装时保存的 **Web 管理端密钥**也不能用于服主登录。

## 给玩家开放创作权限

1. 让对方先在玩家登录页面注册账号。
2. 服主进入“**创作管理 → 创作权限 → 新增**”。
3. 搜索并核对玩家，开启创作端。
4. 按需要授予新建、编辑、导入、导出工程和管理模型等能力，保存。
5. 让玩家重新打开 Creator。

只需要玩游戏的玩家，不需要这些权限。

## 创建日常管理员

服主先在“**服主管理**”中建立权限组，再创建独立管理员账号。只授予对方实际需要的功能，例如玩家管理或游玩地图管理。

管理员只会看到获授权的页面。人员退出管理后，及时停用其账号；不要多人共用服主密钥。

## 查看和处理玩家

在玩家列表搜索账号，核对用户 ID 后查看资料或处理处罚。封禁时填写原因和期限；限制 IP 前注意同一网络下可能有其他玩家。

遇到账号异常，可查看登录和安全记录。删除账号前仔细阅读确认信息。

## 使用创作 CLI

需要在本机编辑器或终端中管理工程、同步地图脚本时，可以使用[创作 CLI](https://docs.box3lab.com/arenapro/zh/cli/)。

先在后台为对应玩家配置创作权限，再创建具有所需权限的 CLI Token。按照 CLI 手册填写 **Creator 地址**并连接；如果地址包含入口路径，也要保留。不要使用 Play 或部署管理器的地址代替。

完整 Token 只在创建时显示，请妥善保存，不要提交到工程或发到群聊；不再使用时在后台撤销。

登录页面需要定制时，另见[登录门户与模板](/guide/login-portal)。

重要调整前，先做好[备份](/operations/backup-and-update)。
