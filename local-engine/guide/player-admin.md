# 玩家管理后台

玩家管理后台用于管理玩家、管理员、权限、安全记录、地图和运行容器。

## 登录

- 服主使用 `BOX_PLAY_ADMIN_TOKEN` 登录 owner 账号。该密钥拥有完整管理能力，不要分享。
- 管理员使用个人账号和密码登录。可见页面与操作权限由权限组决定。

多次输入错误密码会触发临时限流。管理员密码需满足登录页面显示的要求。

## 管理玩家

1. 在玩家列表搜索或筛选目标玩家。
2. 核对用户 ID 后查看资料、导出 CSV 或执行批量操作。
3. 删除账号前完成页面要求的二次确认。删除可能无法恢复。
4. 封禁玩家时填写原因，并选择永久或限时；IP 封禁前确认不会影响共享网络中的其他玩家。
5. 需要排查问题时，记录时间、用户 ID、管理员账号和错误信息，并查看安全记录。

## 管理员与权限

1. owner 为每位管理员创建独立账号，并选择权限组。
2. 按职责授予“查看”或“编辑”权限；编辑权限会自动包含查看权限。
3. 保存前查看权限影响预览，确认菜单、可用操作及受影响账号。
4. 人员离开时停用账号。删除正在使用的权限组前，先将管理员移到其他组。

后端也会检查权限；手工调用接口不能绕过权限限制。

## 创作权限与 CLI Token

- 在“创作权限”中选择玩家并授权；撤销后该玩家失去创作权限。
- 创建 CLI Token 时选择权限并立即复制。完整 Token 只显示一次。
- Token 泄露时立即撤销并重新签发；撤销后无法恢复。

## 地图与容器

- 在“游玩地图”导入、预览、更新或删除 `.boxplay`；详情见[游玩地图管理](/guide/play-maps)。
- 在“容器管理”查看地图运行状态、资源用量，配置运行方式和资源组；详情见[容器与资源管理](/guide/maps-and-containers)。

## 定期检查

1. 查看登录失败和安全记录。
2. 检查管理员账号及权限组变更。
3. 撤销不再使用或疑似泄露的 CLI Token。
4. 备份重要地图包和 PostgreSQL 数据。
