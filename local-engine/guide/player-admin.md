# 玩家管理后台

玩家管理后台用于管理玩家、管理员、权限、安全记录、游玩地图和容器。服主可以使用 `BOX_PLAY_ADMIN_TOKEN` 登录 owner 身份，也可以创建权限受限的管理员账号。

## 登录方式

### 服主登录

使用服主管理密钥登录。该密钥对应 owner 身份，拥有完整管理能力，不能分配给普通账号。

### 管理员账号登录

管理员使用自己的用户名和密码登录。管理员可以修改自己的密码，实际可见菜单和可执行操作由权限组决定。

管理员密码应至少满足页面显示的长度和复杂度要求。多次失败登录会触发临时限流。

## 玩家管理

玩家列表用于：

- 搜索和查看玩家
- 查看玩家基本信息
- 修改允许编辑的玩家资料
- 批量选择玩家
- 导出玩家 CSV
- 删除账号

删除账号属于高风险操作，应核对用户 ID，并按页面要求完成二次确认。删除后可能无法恢复。

## 安全管理

### 账号封禁

可以按账号封禁玩家，并填写：

- 封禁原因
- 永久或限时
- 到期时间

### IP / 设备封禁

用于阻止指定 IP 或设备再次登录。应谨慎使用 IP 封禁，因为共享网络中的多个玩家可能使用同一公网 IP。

### 安全记录

安全记录用于排查登录、封禁和高风险操作。记录中会包含相关用户 ID、操作对象、结果和时间等信息。

排查时建议同时记录：

1. 发生问题的准确时间。
2. 玩家用户 ID。
3. 管理员用户名。
4. 请求结果和错误信息。
5. 对应服务日志。

## 创作管理

### 创作权限

只显示已经获得创作权限的玩家。点击“新增”后选择玩家并授予权限；撤销后该玩家不再出现在授权列表中。

### CLI 令牌

CLI 令牌用于 APC CLI 操作。创建时选择权限，创建完成后页面只显示一次完整 Token，应立即复制并安全保存。

令牌列表支持：

- 查看已分配的令牌
- 查看授权 Token 数
- 编辑令牌权限
- 撤销令牌

令牌撤销后不能恢复。如果 Token 泄露，应立即撤销并重新签发。

## 游玩管理

“游玩地图”用于导入、检查、更新和删除 `.boxplay` 地图包。它不是 owner 专属菜单，拥有对应权限的管理员也可以操作。

导入前可以查看地图包内的地图、脚本、图片、音频和其他资源。确认内容后才会安装到地图库。

## 容器管理

容器管理包含：

- 游玩端地图运行时
- 创作端地图运行时
- 地图容器配置
- 资源组

运行中的地图可以查看名称、地图 ID、房间和资源使用情况。根据状态可以执行销毁或重启。

## 管理账号

owner 可以创建、停用、启用和删除管理员账号，并分配权限组。

建议：

- 每位管理员使用独立账号。
- 不共享 owner 密钥。
- 离职或不再参与管理时立即停用账号。
- 定期检查长期未登录的管理员。
- 高风险操作启用管理员密码二次确认。

停用账号后，登录页面应明确提示“账户已停用”，而不是显示普通密码错误。

## 权限组

权限组按后台菜单分类，每项能力分为“查看”和“编辑”：

- **查看**：可以打开页面并读取数据。
- **编辑**：可以新增、修改、删除或执行操作。

选择“编辑”时，会自动选择对应的“查看”。只要编辑仍被选择，对应查看就不能取消。

保存前使用权限影响预览检查：

- 哪些菜单会显示
- 哪些操作按钮可用
- 哪些管理员正在使用该权限组
- 修改后会影响多少账号

正在被管理员使用的权限组不能删除。需要先为相关管理员更换权限组，确保使用人数为零，再删除。

::: important
前端隐藏菜单只是使用体验的一部分，后端 API 也会检查对应权限。即使手工请求接口，没有权限的管理员也不能执行操作。
:::

## 审计建议

正式环境建议定期检查：

- 管理员登录失败和锁定记录
- 权限组变更
- 管理员账号创建、停用和删除
- 玩家删除与封禁
- CLI 令牌签发和撤销
- 地图导入、更新和删除
- 容器销毁、重启和资源配置修改
