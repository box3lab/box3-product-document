# 地图组与地图

一个地图组包含**一个主地图**，以及按需添加的副地图。不需要多个场景时，只用主地图就能完成一个游戏。

## 什么时候用副地图

| 内容 | 常见用法 |
| --- | --- |
| 主地图 | 大厅、出生点、选择关卡 |
| 副地图 | 不同关卡、战斗场景、单独的房间 |

同组地图可以共用组资源和组数据。添加副地图后，还需要在玩法中配置传送；创建副地图本身不会自动产生传送入口。

## 制作和发布

1. 在 Creator 中确认主地图正确，再添加需要的副地图。
2. 逐张打开并保存，检查模型和脚本。
3. 从主地图测试进入各副地图，以及返回大厅。
4. 导出时选择地图组范围，避免漏掉副地图。
5. 导入 Play 后，再用玩家账号检查传送和多人房间。

## 地图 ID 和游玩地址

地图 ID 用于识别地图，名称用于展示，游玩地址中的访问 ID 可以按后台设置调整。修改名称或访问 ID，不需要手工改地图内部文件。

配置传送或向维护者反馈问题时，复制页面显示的地图 ID，不要用地图名称代替。

## 运行设置怎么选

首次使用，地图组共用默认运行设置即可。只有某张地图明显需要不同的资源或房间上限时，再单独调整，见[地图运行与资源管理](/guide/maps-and-containers)。

删除地图组会影响主地图和副地图，操作前先导出整组工程或保留发布包。
