# 地图组与地图

地图组用于组织可互相传送并共享组数据的一组地图。每组包含一个主地图和零个或多个副地图。

## 结构与配置

- **主地图**：地图组入口，可用于大厅、出生点和玩法选择。删除主地图对应的地图组会影响整组地图，操作前先备份。
- **副地图**：用于关卡、战斗房间或其他独立场景，可共享地图组资源和数据。
- **地图 ID**：系统稳定标识。配置容器、绑定 CLI 工程或排查日志时，使用页面显示的 ID，不要使用地图名称或版本号代替。

配置容器时选择：

| 范围 | 适用情况 |
| --- | --- |
| 地图组 | 主地图和全部副地图使用相同配置 |
| 单个地图 | 某张地图需要不同的资源、玩家上限或隔离方式 |

## 测试地图组

1. 确认主地图设置正确，所有副地图可以打开。
2. 检查传送目标使用正确的地图 ID。
3. 使用测试玩家从主地图传送到每张副地图。
4. 测试多名玩家进入同一房间和创建多个房间。
5. 检查玩家退出后的房间状态及空闲回收。
6. 验证地图组资源、脚本和存档完整。

容器运行方式与资源限制请阅读[容器与资源管理](/guide/maps-and-containers)。
