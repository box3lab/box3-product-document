# 使用启动器

启动器用于管理本地引擎的配置、镜像、服务、许可证和备份。桌面启动器与 Linux Web 管理端的主要功能一致。

## 服务总览

“服务总览”显示各服务的状态、地址和常用操作。

常见状态：

| 状态 | 含义 |
| --- | --- |
| 未启动 | 容器当前没有运行 |
| 启动中 | 容器已经创建，仍在等待健康检查 |
| 运行中 | 服务健康，可以打开 |
| 异常 | 容器退出或健康检查失败 |

常用操作：

- **启动**：创建或恢复对应容器。
- **停止**：停止容器，不删除数据。
- **重启**：使用当前配置重新启动容器。
- **打开**：使用浏览器打开服务地址。

::: tip
关闭桌面启动器窗口不会停止容器。需要释放资源时，请在服务总览中停止服务，或使用 Docker 管理工具停止对应容器。
:::

## 启动创作端和游玩端

如果只制作地图，可以只启动创作端。如果要导入发布包、注册玩家或测试多人房间，需要启动游玩端。

| 场景 | 建议操作 |
| --- | --- |
| 编辑地图和模型 | 启动创作端 |
| 测试发布后的地图 | 启动游玩端 |
| 从创作到游玩完整测试 | 启动全部服务 |
| Linux 服务器只提供游戏 | 只启动游玩端 |

停止服务不会删除地图、工程、数据库、配置或许可证。

## 数据配置

“数据配置”包含：

- PostgreSQL 模式和连接信息
- Redis 模式和连接信息
- 访问范围和公网地址
- 各服务端口
- 地图、模型和备份存储位置
- 注册开关与容量设置
- 服务使用的安全密钥

修改数据库、存储目录或端口后，通常需要重启相关服务才能生效。保存前先确认新值不会与其他程序冲突。

### 修改数据目录

Linux 可以把持久文件迁移到独立数据盘，例如：

```text
/data/BoxEngineData
```

迁移前必须停止业务服务。迁移范围包括 Creator 工程、Play 地图、VOXA 数据、构建产物和启动器备份；内置 PostgreSQL 和 Redis 使用 Docker 卷，不会跟随文件目录一起移动。

## 许可证管理

许可证页面用于：

- 查看设备 ID
- 导入 `.boxlic`
- 查看授权状态与有效期
- 检查许可证错误

许可证与设备绑定。重装系统、更换设备或丢失安装密钥后，设备 ID 可能变化。

## 数据与备份

启动器可以创建、导入、导出和恢复文件数据备份。恢复前会停止相关服务，避免运行中的文件继续写入。

启动器备份不包含 PostgreSQL。完整备份还需要单独导出数据库，具体见[备份与恢复](/operations/backup)。

## 性能监控

性能监控显示长期运行容器的 CPU 和内存趋势，可用于判断：

- 是否需要提高地图资源上限
- 是否有脚本持续占用 CPU
- 是否接近容器内存上限
- 是否有异常容器反复重启

`100%` CPU 通常代表完整占用一个 CPU 核心，不代表整台机器的所有 CPU 都已用完。

## 工程运行时

工程运行时会按创作端和游玩端列出正在运行的地图进程，并显示 CPU、RSS 内存和运行时长。

地图空闲时显示 `0.0%` CPU 属于正常现象。资源数据用于排查运行状态，不等同于资源组配置的上限。

## 查看日志

桌面启动器主要显示状态和关键错误。需要完整日志时，使用 Docker Desktop，或执行：

```bash
docker ps
docker logs <容器名称>
```

Linux 服务器可以使用安装目录中的日志脚本：

```bash
cd /opt/box3-engine
./logs.sh player-service
./logs.sh play
./logs.sh creator
```

日志可能包含用户标识、IP 或内部路径。向他人提供日志前应移除敏感信息。
