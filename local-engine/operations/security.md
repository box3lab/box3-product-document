# 账号与访问安全

第一次使用先跑通[首次启动](/getting-started/first-start)。对外开服时，再重点做好下面几件事。

## 不分享管理密钥

- 玩家使用自己的账号，不需要服主密钥。
- Web 部署管理端密钥和服主密钥用途不同，都不要放进截图、地图脚本或公开聊天。
- 参与管理的人使用独立管理员账号，按职责分配权限。
- 怀疑泄露时，更换密钥或撤销相关登录凭证，并检查安全记录。

## 公网使用 HTTPS

通过[访问设置](/guide/network-access)配置域名和证书。玩家使用 Play 与登录页面，部署管理器和后台只提供给可信人员。

管理端口可限制为自己的 IP，或使用 SSH 隧道访问。不要为了方便连接而开放数据库、Redis 或 Docker 管理接口。

## 只导入可信内容

导入 `.boxplay` 前，查看地图与脚本预览。预览不会执行脚本，但运行游戏时会执行，所以不要直接运行来源不明的地图包。

地图运行的 CPU、内存和房间上限可以在[资源管理](/guide/maps-and-containers)中控制。密码和管理密钥不要放在玩家可以下载的内容里。

## 保留可恢复的备份

按[备份与更新](/operations/backup-and-update)保存作品、游戏包和数据库备份。备份应放在其他设备或安全存储中。

遇到连接或权限问题，不要删除数据库卷、重置所有目录权限，或把目录统一设成任何人可写。
