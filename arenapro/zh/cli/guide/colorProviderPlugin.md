# 颜色可视化与拾色器：告别纯手写颜色值

### 1.1 适合解决的痛点

在没有辅助工具时，调色大多是这样：

- 在代码或配置里**手写 RGB 颜色值**；
- 调整一两个颜色常常要经历：改值 → 保存 → 切回 Arena → 看效果 → 不满意再回去改。

### 1.2 扩展程序提供的能力

启用颜色可视化与拾色器功能后，你可以获得：

- **颜色预览小块**：

  - 在编辑颜色常量的地方，直接看到一个小色块预览当前颜色；
  - 一眼就能区分「这是主色」「这是背景色」「这是警告色」。

- **内置拾色器**：

  - 点击色块或相应入口，可以打开拾色器；
  - 选定颜色后，扩展程序自动把对应的颜色值回写到代码或配置中。
